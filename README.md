# TVPlayer Release

TVPlayer 的发布仓库，只存放 APK 安装包与更新清单（manifest.json），不包含源代码。

- 安装包：见 [Releases](https://github.com/caoyangcy/TVPlayer-release/releases)
- 更新清单：`manifest.json`（通过 GitHub Pages 提供）
- 应用内更新源可填 `caoyangcy/TVPlayer-release`（GitHub Release 模式），或清单地址 `https://caoyangcy.github.io/TVPlayer-release/manifest.json`（清单模式）
